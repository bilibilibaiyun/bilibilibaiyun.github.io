# 白云工具盒

> 精选工具 · 实用网站 —— 健谈的白云 出品

这是「白云工具盒」的 GitHub Pages 站点源码，托管于 <https://bilibilibaiyun.github.io/>。

站点内容整理自 B 站 UP 主 [健谈的白云](https://space.bilibili.com/3706992367504041) 的短视频，聚合了每期视频里介绍过的实用工具与软件，并提供**下载链接**、**GitHub 项目地址**和**视频教程链接**。

## 功能

- 🛠️ **实用工具**：按「电脑工具 / 影音娱乐 / 手机工具 / AI 智能 / 网盘传输 / 其他工具」分类，每个工具附下载、GitHub 与教程视频
- 🌐 **实用网站**：按「AI 工具 / 设计素材 / 在线工具 / 资源获取 / 学习知识 / 休闲娱乐 / 音频素材 / 网盘传输」分类的导航
- 🔍 全局搜索（支持名称 / 描述 / 分类，快捷键 `Ctrl+K`）
- 🌙 / ☀️ 深色 / 浅色主题切换
- 📱 响应式布局，适配手机与桌面

## 结构

- `index.html` —— 站点唯一页面（结构与数据内联，无构建依赖）
- `images/` —— 站点图标资源
- `reader/` —— 独立的「开源阅读网页版」子应用

## 免责声明

所有软件仅供学习交流，请于下载后 24 小时内删除。资源来源于「健谈的白云」的 B 站视频。
